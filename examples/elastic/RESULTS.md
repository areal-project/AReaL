## 计算口径

| 指标         | 定义                                                                                                                 |
| ------------ | -------------------------------------------------------------------------------------------------------------------- |
| 总耗时       | `invocation.elapsed_seconds`，包含 `run_demo` 初始化至退出清理／绘图；不含入口前置输入哈希检查。旧记录缺失时不补推。 |
| Actor GPU 秒 | 每代 STARTING→STOPPED 秒数乘 4 后求和，包含启动、保存和释放；不是显存利用率积分。                                    |
| 中途离线窗口 | 已完成更新后的 STOPPED→下一次 STARTING，且随后恢复并继续训练；排除首次启动前和最终退出。                             |
| 更新耗时     | 更新后 READY 事件的 `update_seconds` 之和，包含权重发布及循环内统计。                                                |
| 有效弹性周期 | 中途真实释放、恢复、继续更新，并有完全离线期间的 rollout 进展证据。LLM 提案不算执行结果。                            |

同时报告占用和总耗时；尚无独立 rollout 资源租约边界，不报告精确总 GPU 秒。显存约每秒采样，采样最大值不代表瞬时峰值。
